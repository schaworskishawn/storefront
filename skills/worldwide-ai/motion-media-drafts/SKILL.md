# Motion media drafts

## Use this when

- An approved brief needs a storyboard.

## Do not use this when

- What the function needs has not been supplied: it reports what is missing and creates nothing, so gather it first.
- The request belongs to another agent's function: it goes through Nexus, not through this procedure.
- The request is to act outside the workspace (send, post, pay, file, or change a live record): this procedure only prepares and stores a result.

## What you need

- Video (required)
- Approved brief (required)
- Format (required)
- Length in seconds (required)
- Claims that may be made
- Approved assets

## Procedure

1. Read the brief, the target length and the approved assets.
2. Lay out scenes that run back to back and add up to the length.
3. Write the script per scene from the brief's facts.
4. Write the shot list using approved assets only.
5. Plan the captions.

## What you produce

- A stored StoryboardPackage record, checked against its declared format before it is kept.
- It waits for a person to accept or reject it.
- Its sources, anything missing, assumptions and warnings are listed with it.

## Checks before you finish

- The scenes' durations add up to exactly the length asked for.
- Every asset is from the approved list.
- The result says nothing was rendered.

## When something goes wrong

- If the brief can't fill the length, say so rather than padding.

## Example

**Request:** "Motion: draft video production plan."

**Result:** A storyboard package draft is stored with timed scenes covering the full duration, script and on-screen text, the asset each scene uses or needs, and a caption plan, waiting for a person's review.

## Limits

- It is a plan, not a video. Rendering or exporting a clip needs a media tool, which isn't connected, and nothing is published.
- Plans a video. Renders nothing and publishes nothing.
- A storyboard is not a video. No rendering tool is connected.
- The wording comes from a model and is checked by code. A person reviews every draft before it is used.
